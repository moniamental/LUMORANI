Icon-only control (search, wishlist, cart, carousel arrows). Always pass `label`.

```jsx
<IconButton label="Warenkorb" variant="hairline"><i data-lucide="shopping-bag"></i></IconButton>
```

`shape="circle"` for header utilities and carousel arrows; `shape="square"` inside cards and toolbars. `variant="gold"` only for a single emphasised action (e.g. newsletter submit arrow).
