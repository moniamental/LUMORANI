Underline dropdown, styled to match `Input`. Use for sorting, sizes and cut selection where a `CutSelector` is too prominent.

```jsx
<Select label="Sortieren" options={["Neuheiten", "Preis aufsteigend", "Preis absteigend"]} />
```

The chevron is a rotated hairline square in `--text-gold` — do not swap in a filled triangle.
